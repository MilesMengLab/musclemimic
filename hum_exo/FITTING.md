# 安装配合调节

在项目根目录运行：

```bash
./scripts/hum_exo.sh fit --device knee_exo
```

浏览器打开 `http://127.0.0.1:8080`。终端保持运行，Ctrl+C 关闭。页面提供右侧和左侧选择，默认同步镜像。绿色轴线表示人体膝轴，黄色轴线表示电机轴。

检查报告、保存路径和错误提示直接显示为文字，保留换行并转义特殊字符。更新脚本后需要重启服务并刷新页面。重启前先保存草稿，重启后点击“加载草稿”恢复已保存的调整。

先调整电机轴向偏置，再调整上下合页角度。电机偏置沿人体膝轴移动整套设备；调整上合页保持电机和小腿部分的位置；调整下合页保持电机位置并改变小腿绑缚姿态。绕膝轴旋转装配体用于改变整套设备的安装方向。以上调整保留 CAD 关节连接关系。

默认开启共轴约束。关闭后可调整前后、上下平移和倾斜，用于检查安装误差。重新开启共轴约束会清除这些偏移。角度单位为度，位置和间隙单位为毫米。

四个彩色测点分别对应大腿上端、大腿下端、小腿近膝端和小腿远端。数值为测点与同侧肌肉显示胶囊的有符号距离，正值表示间隙，负值表示进入显示几何。启用“点击设备网格重新放置测点”后，选择部位并点击该绑缚表面可重新选点。骨骼和肌肉可以临时隐藏，方便选择被遮挡的表面。

设置各点的目标间隙并勾选参与自动贴合，点击“按测点目标自动贴合”。求解器在关节范围和共轴约束内调整安装，显示各目标残差。一个刚体上的多个目标可能无法同时实现，应根据残差调整目标或取消部分测点。测点距离只描述局部几何，需要继续运行完整干涉检查。

保存位置可以在“草稿路径 / 文件名前缀”中输入，也可以点击“选择保存目录”浏览本机目录、进入子目录或创建文件夹。目录选择对应运行脚本的机器。保存成功后，路径框自动显示新文件的完整路径，点击“加载草稿”可以恢复该版本。

“保存草稿与模型”每次自动添加本地时间和微秒后缀，例如：

```text
generated/knee_exo/fitting/draft_20261104-234500-123456.json
generated/knee_exo/fitting/draft_20261104-234500-123456_model.xml
generated/knee_exo/fitting/draft_20261104-234500-123456_model.json
```

第一个文件保存安装变换、关节角度、测点及 CAD 校验信息；后两个文件为独立 MuJoCo 模型和构建报告。连续保存时使用同一文件名前缀，不重复叠加时间后缀；同一微秒发生重名时追加序号。旧版 `draft.json` 和所有历史版本保留。草稿操作不更新默认设备资产。

硬约束是两侧人体膝轴与电机轴共轴，当前容差为轴线距离不超过 0.05 mm、夹角不超过 0.01 度。轴线不满足要求时，“保存草稿与模型”和“检查并应用到新训练”均不生成输出文件、不修改启用配置。可以继续在网页中调整安装。

骨骼相交、手部干涉及肌肉显示几何重叠属于软约束，只显示警告并写入报告，不阻止生成或应用。肌肉显示重叠超过 0.5 mm 时触发警告。界面分别展示“轴线硬约束”和“软约束警告”，不会把肌肉重叠报告为轴线错位。

“检查并应用到新训练”先生成带时间后缀的草稿和模型，再将安装保存至 `assets/knee_exo/profiles/fitting_profile_时间.json`，由 `mounting.json` 指向启用版本。原配置和上一版本备份至 `generated/knee_exo/fitting_history/`。每次应用均保留新版本，包括安装位置未变化时；已有资产配置文件不会被覆盖。URDF、STL 和质量惯量保持不变。后续新训练和安装预览使用新配合，已有 checkpoint 继续使用原模型快照。

这是中立位静态几何调节工具。红色几何表示肌肉路径显示，不是有厚度的皮肤模型；测点间隙不表示绑缚压力。完整检查不证明运动过程中无干涉，也不替代动态绑缚负载和步态评估。

公共界面位于 `scripts/hum_exo/fit.py`，会话接口位于 `hum_exo/fitting.py`。膝关节运动学、测点和保存逻辑位于 `hum_exo/devices/knee_exo/fitting.py`，模型构建通过安装配置接入。其他设备可实现适配器的 `create_fitting_session()` 使用同一界面。
