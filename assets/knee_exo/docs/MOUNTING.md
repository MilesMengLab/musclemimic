# MyoAssist 标准的安装校准

当前有效安装：按用户选择，优先大腿贴合和手部无干涉，允许减小移动量。电机轴向偏置为 54.5 mm，上合页 -7.4 度、下合页 +0.123989 度。相对请求前的 55 mm 安装，电机净内移 0.5 mm；电机旁绑缚上端固定 CAD 顶点区的中心沿膝轴向内净移动约 0.702 mm。骨骼三角面最小间隙约 1 mm，未检出骨骼交叉。大腿肌肉显示重叠约 0.438 mm，仍在允许的 0.5 mm 内；右手显示间隙约 0.290 mm，左手显示间隙至少 1 mm。膝轴夹角小于 0.0001 度，轴线共线。

请求的电机内移 3 mm、邻近绑缚净内移 2 mm 候选已做数值验证：可保持膝轴与手部无干涉，但大腿肌肉显示穿入约 2.329 mm。另一候选电机内移 0.5 mm 而绑缚上端仍净内移 2 mm，会使小腿下部与腓骨交叉。这些候选未应用到默认安装。截图和测量位于忽略目录 `generated/knee_exo/candidates/`。

绑缚移动量以小腿网格在基准中立位最高点向下 75 mm 范围内固定顶点集合的中心在共同膝轴方向的投影变化计算。它是指定上端区域的位移，不等于整个小腿部件最小骨骼间隙。测量报告为 `generated/knee_exo/adjustment_report.json`。

下合页精确拟合在近似网格距离与真实三角面根区间不一致时会扩展搜索区间，遵守 CAD 关节限位。安装构建同时检查前臂、手和手指对应肌肉路径，手部交叉阈值固定为零，大腿允许轻微贴合。

以下为历史调整过程。

最新贴合调整：电机沿共同膝轴从 56 mm 向内靠近 1 mm，当前轴向偏置为 55 mm。下合页改为约 -0.257684 度，小腿最近骨骼间隙从 5 mm 调整为 3 mm。为了补偿向内移动导致的大腿交叉，上合页从 -6 度调整为 -7 度，肌肉显示重叠约 0.327 mm，低于允许的 0.5 mm。电机与邻近的小腿绑缚都更靠近人体，机构没有断开或缩放。

相同中立位下，电机旁小腿绑缚上方 75 mm 区域对胫骨的表面间隙约从 14.549 mm 降至 14.396 mm，对腓骨约从 20.113 mm 降至 19.069 mm。整个小腿部件最近骨骼间隙为 3 mm；分区间隙与整体最小值是不同指标。

下文保留此前校准过程，当前有效值以 `assets/knee_exo/mounting.json` 和新构建报告为准。

2026-11-04 按用户要求，以 MyoAssist 的机构和膝轴共线为标准，进一步消除新人体大腿最上端的明显穿模。用户允许与肌肉轻微贴合。原项目文件、左右 URDF、网格和惯量均保持不变，修改位于本目录。

新人体的膝轴和骨骼几何不同，因此重新求挂载变换与上下合页角度。上合页拟合时固定电机壳体，转动真实关节带动大腿绑缚；下合页带动完整小腿部件。没有单独平移、缩放网格或断开连接件。

此前上合页 -4.287156 度、下合页 -3.110403 度的版本只检查骨骼，虽然骨骼间隙约 5 mm，大腿部件仍与阔筋膜张肌、股外侧肌的显示路径交叉。新检查包含 MuJoCo 实际渲染的肌肉/肌腱胶囊半径、端点与三角网格表面距离，覆盖线段穿面和边缘最近点。

当前上合页为 -6 度，电机沿共同膝轴从原 45 mm 向外移动 11 mm，轴向偏置为 56 mm。下合页重新拟合为约 -0.539131 度，保持小腿对腓骨最近间隙约 5 mm。大腿部件对全部可见骨骼的最近间隙约为右侧 10.653 mm、左侧 11.048 mm，最近对象为手指骨，无骨骼网格表面交叉。

按用户指定改为 -6 度后，大腿部件与可见肌肉路径两侧各有一个胶囊约 0.289 mm 的轻微显示重叠，按允许轻微贴合的要求保留。配置中的 `upper_visual_gap_m=-0.0005` 允许最多 0.5 mm 的肌肉显示重叠。电机轴和小腿配合保持不变。这是显示几何的检查，不是皮肤或软组织接触模型。

中立位电机轴与人体膝轴夹角约 0.000012 度，轴线距离小于 0.000001 mm。电机轴心沿轴线位于外侧 56 mm，外侧电机轴心与骨内膝轴心因此保持距离。共轴要求轴线重合，允许轴心沿轴线分开。

原迁移版本为避开 MyoFullBody 的粗碰撞胶囊，将设备额外向外移动 34 mm，导致绑缚偏远。本次移除了该偏移。空心绑缚的凸包也会填充开口，因此同侧股骨、胫骨、髌骨与安装部件排除内部碰撞，由固定安装和数值 weld 传力。设备的碰撞标志保持启用，地面、对侧腿及其他外部碰撞继续保留。该设置是数值绑缚，不模拟皮肤或绑带压力。

`assets/mounting.json` 设置 56 mm 轴向偏置、-6 度上合页、允许肌肉贴合和 5 mm 小腿骨骼目标间隙。`mounting.py` 校准真实合页，`geometry.py` 执行网格与可见肌肉胶囊的距离和交叉检查，`model.py` 将结果写入训练模型及 JSON 报告。拟合缓存包含肌肉胶囊、骨骼和设备网格、人体中立姿态、关节及挂载目标的校验信息，输入变化后重新计算。

安装检查命令：

```bash
./scripts/with_proxy.sh uv run --extra cuda python -m knee_exo.preview
```

绿色表示人体膝轴，黄色表示电机轴。加入 `--render` 可在 `generated/mounting_preview/` 保存正面、侧面、斜视截图与轴线测量。该命令显示与新训练相同的静态中立位模型。

`knee_exo.play --preview` 展示参考动作拟合，其中被动合页随参考动作变化。三个设备自由度仍不能在全部动作中严格匹配人体耦合膝的六维绑缚位姿。上合页 -7 度版本三段示例动作的位置拟合残差峰值分别为 15.376 mm 和 16.906 mm，仍需检查动态负载。中立位共轴与表面间隙验收不等于整个运动过程的共轴或无干涉认证。

旧 checkpoint 播放和续训继续读取自己的模型快照，新预览与新实验使用本次校准模型。
