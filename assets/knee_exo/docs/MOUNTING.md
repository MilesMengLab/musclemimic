# 膝关节安装与接触模型

有效安装由 `assets/knee_exo/mounting.json` 和其 `fitting_profile` 指向的配置共同决定。交互配置包含左右挂载位置、旋转、合页角度和测点；基础参数不能单独代表启用后的最终安装。

在共同膝轴上平移电机可以改变人体与设备的横向间距，同时保持轴线重合。上、下合页分别调整大腿和小腿的机构姿态，保留 CAD 连接关系。不要通过单独移动网格来断开电机或连接件。

中立位轴线夹角不大于 0.01 度、轴线距离不大于 0.05 mm 是生成和应用安装的硬约束。骨骼、肌肉或手部干涉作为警告显示。几何审查针对中立位，不能据此判断整个动作过程均无干涉。

人体和设备通过挂载关系及 MuJoCo weld 约束传力。对安装处的同侧内部碰撞作排除，设备碰撞标志仍启用。这种理想化数值绑缚不模拟皮肤、软组织或绑带压力。肌肉显示路径与 CAD 轻微重叠属于几何现象，需结合动态约束力和运动稳定性判断影响。

```bash
./scripts/hum_exo.sh preview --device knee_exo
./scripts/hum_exo.sh preview --device knee_exo --render
./scripts/hum_exo.sh fit --device knee_exo
```

预览中绿色为人体轴，黄色为设备轴。`--render` 保存三个视角和 `alignment.json`。安装编辑的操作、保存和应用规则见 [FITTING.md](../../../hum_exo/FITTING.md)。

参考初始化会拟合三个设备关节，使人体目标保持原定义。设备与人体的机构不同，整个轨迹可能存在绑缚位置和姿态残差；训练目录的 `reference_fit.json` 记录这些误差。评估步态和助力效果前，需要检查动态绑缚负载及电机关闭对照。

已保存策略使用训练时的模型快照。应用新的安装配置只影响后续构建和新训练。
