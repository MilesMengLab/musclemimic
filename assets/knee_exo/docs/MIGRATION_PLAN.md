# 膝关节外骨骼协同训练迁移清单

本清单基于 2026-11-04 的本地代码审查。MuscleMimic 基线为 `47b653d`，开发分支为 `knee-exo`。按用户要求，迁移实现集中在仓库根目录 `knee_exo/`，下文中的原规划模块路径作为职责说明保留。

当前已实现设备导入、轴线对齐、数值绑缚、参考初态拟合、26 维传感器、双 actor 与共同 critic、激活与设备用力代价、训练表格、保存与续训、CPU 播放和 NumPy 设备 actor 导出。短训练验证执行流程，任务的科研验收仍以各节标准为准。当前中立位大腿部件已检查肌肉交叉，小腿对骨骼最近间隙约 5 mm，运动参考位置残差峰值约 17 mm，完整运动范围的受力和助力收益尚待验证。详细运行命令与限制见 [README.md](README.md)。

目标组合为 MyoFullBody、现有双侧膝关节外骨骼、独立人体与设备策略，以及共同评价的人机协同训练。初版设备策略使用当前时刻的 26 维传感器输入，输出左右两个膝关节电机命令。人体策略继续使用动作模仿所需的仿真状态和参考目标。

- [ ] 在参考帧重置后求与人体姿态一致的设备位置和速度，并检查闭环残差。

- [x] 为模仿奖励、未来目标和轨迹缓存明确人体关节集合及额外设备自由度的处理规则。

## 6. 26 维设备观测

来源为 `myoassist_utils/knee_imu.py`、`imu_mounts.json` 和 `imu26_input_schema.json`。

- [x] 按左大腿、右大腿、左小腿、右小腿顺序输出每个 IMU 的三轴加速度和三轴角速度，共 24 维。
- [x] 追加实际右侧设备编码器角度和角速度，共 26 维。
- [ ] 记录加速度为传感器局部坐标系比力，单位 m/s²；陀螺仪为 rad/s；编码器为 rad 与 rad/s。校验正方向、采样周期和重力响应。
- [x] 扩展观测类型与分组，按名称生成索引；分别定义人体、设备和 critic 的输入。
- [x] 筛选肌肉执行器观测。当前 MyoFullBody 的默认观测循环遍历全部执行器，增加电机后需要适配。
- [x] 为设备输入建立独立、可导出的归一化参数。初版保持当前帧 26 维接口，人体策略的未来目标和历史配置独立处理。

验收：设备 actor 的输入仅来自规定的 26 个通道；CPU 与 GPU 的传感器单位、方向和排序一致。人体参考目标、仿真真值和左侧编码器由输入隔离检查覆盖。

## 7. JAX 人机协同策略与 PPO

来源为 `rl_train/train/policies/rl_agent_exo.py` 和 `network_index_handler.py`。其核心结构是独立人体 actor、设备 actor 和共同 critic，在同一环境奖励下联合优化。

- [x] 在 Flax 实现两个 actor 和一个共同 critic，并配置各自的观测分组与网络尺寸。
- [x] 按执行器名称映射人体肌肉动作和两个电机动作；在构建时检查重复、遗漏与越界。
- [ ] 为两个动作分支配置分布与标准差，核对联合 log-prob、entropy、PPO ratio 和梯度更新。
- [ ] 核对动作缩放、裁剪和肌肉控制约定，保留训练时动作与实际执行动作的明确关系。
- [x] 扩展网络构造、优化器、推理、checkpoint 元数据以及保存、恢复接口。
- [ ] 评估官方人体权重的迁移条件，包含观测维度、历史、归一化、参数名称与动作输出。定义显式加载适配器或重新训练方案。

验收：两个 actor 均有有效梯度，设备输入隔离成立；保存后推理一致，恢复后可继续训练。原 MyoAssist 的 SB3 权重作为历史实验资料保留，新结构使用匹配的 checkpoint。

## 实施顺序与代码边界

顺序为官方基线、设备预览、物理连接、轨迹重置、观测、协同网络、单动作联合训练、多动作与评估。GPU 模型兼容性在物理连接阶段验证。

当前实现集中在 `knee_exo/`：`model.py` 负责设备组合，`environment.py` 和 `reference.py` 负责观测与初态，`reward.py` 负责奖励，`policy.py` 负责网络，`configs/` 保存配置，`train.py`、`play.py` 和 `export.py` 提供入口，`console.py` 记录表格和指标。底层通过原项目接口接入。

当前工作集中在膝关节设备和协同训练。原项目其他设备目录、SB3 训练循环、旧人体观测索引及纯前向行走速度缩放逻辑保留在原项目。动作参考由 MuscleMimic 现有数据流程提供。

首个可验收交付为 MyoFullBody 与双侧外骨骼的同源预览和动力学模型，附轴线、间隙、活动范围、力矩方向及 CPU/GPU 短轨迹检查报告。
